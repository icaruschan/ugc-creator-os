# System Prompts

This directory contains master system prompt instructions designed to configure external LLMs (like Google AI Studio or Grok) to act as creative partners.

## Files

- **`grok-master-system-prompt.md`**: The master configuration prompt for Grok, turning it into a creative director and script analyst.
- **`ScriptWriter_Google_AI_Studio_System_Prompt.md`**: The system instructions used in Google AI Studio to instantiate a specialized scriptwriter capable of outputting high-conversion hooks and storyboard descriptions.\n
