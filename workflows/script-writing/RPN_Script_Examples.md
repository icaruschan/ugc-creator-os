# RPN Script Examples

These examples are for **pattern learning**, not verbatim copying.

Use them to learn:

- how strong claims are opened
- how stakes show up by line 2
- how bridge lines create motion
- how proof beats are layered
- how endings often zoom out into a larger takeaway

Do **not** copy exact language by default.
