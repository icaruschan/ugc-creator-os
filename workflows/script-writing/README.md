# Script Writing Workflows

This directory contains the tools and prompt engines used to draft dialogue, visual scripts, and narrator audio.

## Files

- **`RPN_Script_DNA.md`**: The core structural framework defining how script lines are mathematically paced and visual directions are formulated.
- **`RPN_Script_Examples.md`**: A bank of validated reference scripts showing how RPN structure is applied.
- **`script-writer-v1.0.md`**: Baseline prompt engine for generating UGC scripts.
- **`script-architect (Gemini tts) -v1.0.md`**: Prompt engine tuned specifically for Gemini, focusing on scripts that are optimized for Text-to-Speech (TTS) voiceovers.
- **`ScriptWriter_V2.0.md`**: Upgraded script generator emphasizing dynamic hook structures.
- **`ScriptWriter_V2.1.md`**: Iteration adding support for pricing/pack breakdowns.
- **`ScriptWriter_V2.2.md`**: Advanced scriptwriter featuring deeper control over visual pacing and emotional transitions.\n
