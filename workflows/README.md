# Workflows

This directory houses the prompt engines and architectural templates used to construct UGC scripts, storyboard frames, and final video compiles.

## Subdirectories

- **`script-writing/`**: Engines for writing hooks, pricing blocks, and full multi-beat commercial scripts.
- **`image-generation/`**: Prompt systems to generate high-fidelity, consistent character sheets and photorealistic still frames.
- **`video-generation/`**: Architectures for compiling video-model motion prompts (for Seedance, Kling, and Veo).
- **`node-prompts/`**: Structured outputs (like JSON builders) and node-to-node connectors for automated pipeline steps.\n
