# Video Generation Workflows

This directory contains the prompts and compilers used to output video motion instructions for AI video models.

## Files

- **`al1sha1-kling-architect-v1.0.md`**: Motion prompt structures specifically optimized for the Kling AI video model.
- **`al1sha1-seedance-architect-v1.0.md`**: Base motion prompt compiler for the Seedance video model.
- **`al1sha1-seedance-ugc-architect-v2.0.md`**: Upgraded Seedance motion compiler designed specifically to preserve UGC realism and avoid waxy CGI styles.
- **`al1sha1-seedance-ugc-architect-v2.1.md`**: al1sha1 Seedance UGC architect with Natural, Precision, and Canva Override modes, exact Voice ID handling, and controlled edit triggers.
- **`al1sha1-veo-architect-v1.0.md`**: Video generation prompts configured for the Google Veo model.
- **`al1sha1-video-architect-v4.6.md`**: High-level visual prompt compiler that sets sequencing rules across multiple shots.
- **`al1sha1-video-core-dna-v1.0.md`**: Baseline physics rules (e.g. wrapper tearing, snapping, oozing rates) and video settings to maintain natural movement.
- **`seedance-ugc-architect-v1.0.md`**: Video compiler mapping static frames to Seedance motion tags.
- **`seedance-ugc-architect-v1.1.md`**: Upgraded Seedance UGC architect with Natural, Precision, and Canva Override modes, exact Voice ID handling, and controlled edit triggers.
- **`gemini-omni-ugc-architect-v1.0.md`**: Google Flow-only Gemini Omni Flash architect for short UGC generation, starting-frame workflows, voice anchoring, performance transfer, and controlled edits.
- **`ugc-video-architect-v3.1.md`**: Prompt engine designed to translate 2D storyboard concepts into physical motions for video models.
