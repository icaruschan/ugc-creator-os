# UGC Creator OS 🎬

> **Photoreal AI User-Generated Content (UGC) Production Operating System & Prompt Architecture**

An end-to-end framework and agentic operating system designed to produce organic, photoreal UGC videos and stills with anti-AI biological realism discipline.

---

## ⚡ Core Philosophy & Operating Principles

1. **Anti-AI Discipline**: Fight the generic AI look — eliminate plastic sheen, artificial skin smoothing, waxy textures, and blown highlights. Every still reads as a real photograph; every video reads as an authentic creator recording on a smartphone.
2. **Conversational Checkpoints**: Deconstruct reference videos, establish what to preserve vs. replace, confirm direction, and only then architect production prompt packages.
3. **Platform Agnostic & Modular**: Built to power top generative engines (Higgsfield, Seedance 2.0/2.5, Nano Banana Pro, GPT Image).
