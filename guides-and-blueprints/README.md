# Guides and Blueprints

This directory contains master strategic workflows, platform documentation, and blueprints outlining the creative methodology for UGC ads.

## Files

- **`AI_UGC_Blueprint.pdf`**: The high-level PDF blueprint detailing the strategy for scaling UGC creation using AI tools.
- **`UGC Deconstructor.md`**: A core analysis framework that breaks down successful ads into their component parts (hooks, transitions, bodies, and calls to action).
- **`seedance-prompt-guide by sirio.md`**: Official/best-practice guide on how to write effective motion and style prompts specifically for the Seedance text-to-video engine.
- **`ugc-toolkit-workflow-guide.md`**: Complete workflow instructions detailing how to use the script, image, and video generators in tandem.\n
